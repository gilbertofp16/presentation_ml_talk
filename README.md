# GenAI Maturity: From Demo to Reliable Production and Agentic Engineering

Gilbert Pochet · MLAI Meetup · 20-minute talk

## Run

Open `index.html` in a browser. No build step.

| Key | Action |
| --- | --- |
| `→` `Space` `PageDown` | Next slide |
| `←` `PageUp` | Previous slide |
| `N` | Toggle speaker notes |
| `P` | Open presenter window (notes, next slide, timer), synced with the main window |
| `F` | Fullscreen |

**PDF export:** open the deck in Chrome, choose Print, then Save as PDF. Each slide prints as one 16:9 page with the notes hidden.

## Structure

```
index.html     slides + speaker notes (<aside class="notes">)
styles.css     layout and theme (one accent colour per section)
deck.js        navigation, notes, presenter sync
```
